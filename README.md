## System Requirements

To run the MuLab 2026 suite effectively, your Windows system should meet the following minimum specifications:
- **Operating System:** Windows 10 (version 1903 or later) or Windows 11.
- **Processor:** Intel Core i5 / AMD Ryzen 5 or equivalent.
- **Memory:** 8 GB RAM minimum (16 GB recommended for large projects).
- **Storage:** 2 GB of available hard disk space for installation, with additional space for project files and sample libraries.
- **Display:** 1280x768 resolution or higher.
- **Other:** A compatible audio interface with ASIO driver support is recommended for low-latency recording and playback.
